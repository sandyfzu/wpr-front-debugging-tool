**Cache context:** the signature flag is named **`cacheMarkerFound`**, not `signatureFound` — the redaction rule classifies `*signature*` names as secret-bearing, and a contract key that the export blanks is a defect; the rename keeps the key and the field out of that family without weakening the rule. `lib/detection/cache-context.ts` owns the five explicit states (`cached`, `uncertain-signature`, `possibly-cached` with an optional bypass flag, `not-detected` with `captured|unavailable|truncated|redacted`, `not-cached`), the verified vendor markers (`sg-f-cache: HIT` → SiteGround; `cf-cache-status` HIT/STALE/REVALIDATED/UPDATING → Cloudflare; EXPIRED/MISS/DYNAMIC/BYPASS/NONE/UNKNOWN are non-serves), and the chip/tooltip/report copy. The generic `x-proxy-cache` host/proxy header is deferred to P14.5 T3 and is never labeled SiteGround. Cache footers are comment-only and prefix-anchored: the full normal phrase plus the white-label `Cached for great performance` and `Optimized for great performance` markers are recognised after `documentElement`, with `Debug: cached@<digits>` parsed inside the matched comment. The hub now awaits its one-shot header fetch on the same-context read and hands the strip the resolved state; the page-analysis log reads the same resolved state after the fetch. The panel derives it from `FdtData` (additive `bypassAttested: true` when the captured URL carries `nowprocket`; `pageHeadersTruncated` reaches the truncated arm). Precedence: cached → signature → served host marker (with bypass qualification) → bypass → header arms. The status bar, Detections summary/support report and the report's `page cache` row read the same vocabulary; "Not cached" appears only with bypass counter-evidence and says WP Rocket's cache (host/CDN layers are separate); a page the plugin did not handle reports "Not applicable (WP Rocket not detected)". Timestamp guards/formatting moved to `lib/detection/cache-time.ts` (single owner, re-exported from `describe`): the display domain is non-negative integer seconds through 9999-12-31 23:59:59 UTC, and `CacheState.seconds`/`CacheSummary.seconds` are null outside it. Badge protocol unchanged.

**Deltas/limits:** Delay's version read keeps the reference order (a delayed script earlier in the document still hides the controller version); the preload-links second signal counts occurrences across scripts, not the whole serialized page; the self-hosted footprint is link-only until D7. `wpr_minify_css`/`wpr_minify_js` declared-but-applied-nothing is pinned by test; no further per-row exception was found.
