## Verified source contract (v4.1.1)

RUCSSTester.js/utils, audited2026-10-06:

- Endpoint `https://mega.wp-rocket.me/support/wpr-rucss-v2.php`; source assembles **`?url=<unencoded page URL>?<unix seconds>[&mobile][&home]`**, including literal second?. **Live verification is a release blocker before changing or trusting this parser contract**, especially page URL already with query. It was source-verified, not proof of current server behavior.
- POST JSON Content-Type, body **only `{safelist}` or `{}`**, redirect follow.200 `contents.shakedCSS` expected; preserve/exclude/prepend/append/replacements client-side. Inject style id **rucss_test_result_style**; successful test marks `(TEST MODE)`.
- Strip `style,link[rel=stylesheet]`; links excluded by raw regex lines (old wildcard helper discarded return); inline preserve matches serialized style substring, but **wpr-usedcss always removable**. Defaults: `#wpcb-quick-actions-menu`, `wpr_rucss_style`, `admin-bar.min.css`, `dashicons.min.css`, `inspector_style`, `rocket-lazyrender-inline-css`. Always apply defaults+user lines (source empty input accidentally removed defaults).
- Ordered global-regex replacement pairs. Original persistence CSV/page localStorage, console tables/URL logs, sticky-disabled submit/classList assignment/unchecked response all replaced, not parity targets.

**Receipt (P13B, 2026-11-05):**

- **N1 — user patterns off every page thread.** Pairs + stylesheet-URL exclusions run in a fresh Web Worker spawned by the **DevTools panel**, terminated at `RUCSS_BUILD_TIMEOUT_MS` 10 s (`lib/rucss-tester/build-client.ts` → `build.worker.ts` → pure `build.ts`; no `Worker` ⇒ `unavailable`, never inline; worker error / `messageerror` ⇒ `failed` at once). Why: a content script cannot start a worker from extension files (worker URL must be same-origin with the page; `blob:`/`data:` hit page CSP), Chromium's MV3 service worker has no `Worker`, an in-thread time box cannot interrupt a regex. Termination evidence (real Chromium 156): `terminate()` returns in 0 ms, the main thread stays responsive, the runaway worker's CPU stops ~2 s later; Node `worker_threads`: `(?:a|[a-z])*$` cut at 300 ms. Realistic load: 50 pairs + 50 exclusions over 2 MiB CSS, 300 links = 83 ms. Inline preserve markers (substring, linear) stay on the page thread. **Sound alternative for a panel-less run (not taken now — no new permission in P13B):** Chromium offscreen document (`offscreen` permission, reason `WORKERS`; verified Chromium 156 `management.getPermissionWarningsByManifest`: **no install warning**) + the Firefox MV2 persistent background page, which can spawn/terminate a Worker (precedent `exclusion-transform-worker`).
- **Protocol.** Panel `runRucssTest(deps)` (`lib/rucss-tester/run-test.ts`): one config read → `prepareRucssRun` (invalid ⇒ nothing sent) → `startRucssTest` → worker build → `applyRucssTest`; typed `RucssTestOutcome` (`config-unreadable`/`invalid-config`/`page-unreachable{step,miss}`/`start-failed`/`build-failed`/`apply-failed`/`applied`); `rucssTabSteps` = bounded guarded asks, relayable (Firefox tab-less panel). Content script `entrypoints/isolated.content/rucss-test/` (top frame): start → background `fetchRucssShakenCss` → snapshot **after** the answer (inline judged here, link URLs returned; ≤5 000 links / 4 Mi chars else `too-many-styles`), page untouched; snapshot dropped after `RUCSS_SNAPSHOT_TTL_MS` (build 10 s + apply 10 s + hop 5 s) or on a newer start (no pinned page elements); apply (current run, once): target `head` ?? root (else `no-document`) → inject `<style id=rucss_test_result_style>` created in the XHTML namespace (an HTML style element even in SVG/XML documents, where `createElement` makes an inert one with `sheet` undefined; verified Chromium 156: XHTML-namespaced style applies on `/svg` and `/xml`) → **not an `HTMLStyleElement` or `sheet == null` ⇒ remove it, `css-blocked`, nothing else touched** (spec: a CSP-blocked inline style gets no sheet; verified Chromium 156: main-world insert under `style-src 'self'` ⇒ null, content-script insert exempt ⇒ sheet) → remove snapshot styles not kept. `rucssTestModeFor(ctx)` → `{applied, runs}` for P13C. Background `entrypoints/background/rucss-fetch.ts`: top-frame http(s) sender, guarded payload, page on the sender's origin, fixed endpoint ⇒ no open proxy (else `refused`, nothing sent; also when the built address passes `requestUrlChars` = page cap 32 768 + `RUCSS_ENDPOINT_URL_OVERHEAD_CHARS`, so every sent request's reply passes the content script's guard); `AbortSignal.any([cancel, timeout 25 s])`, `credentials:'omit'`, `no-store`, 2 MiB capped read; per-tab single flight + tab close ⇒ `cancelled`; logs kind only. Deadlines single-sourced `lib/rucss-tester/deadlines.ts`.
- **Deltas vs source.** Result CSS set via `textContent` (source `innerText` turned line breaks into ignored `<br>` children, merging lines). SVG `<style>` elements are judged against the preserve markers (source compared `nodeName === 'STYLE'`, so SVG styles — `nodeName` `style` — were always removed): a marker expresses "keep this style" wherever it sits, and WP Rocket's own inline-style handling does not distinguish SVG ones. An exclusion pattern the engine gives up on reports `exclusion-failed{line,message}` (pairs: `pattern-failed{index,message}`). `run-plan`: `decideInlineStyle`/`decideLinkStyle` split, exclusions carry their line. `utils/random-id` shared.
- **Tests.** Guards hostile/bounds (page + request URL bound both sides), background sender/origin/no-proxy/timeout≠cancel/supersede/oversize/no address in logs, `registerRucssFetch` production wiring (global `fetch`, real clock/signal, tab close ⇒ `cancelled`), executor on happy-dom (every failure ⇒ identical style markup; exact removals; `css-blocked` rollback; SVG markers; line breaks; snapshot TTL with fake timers), worker entry, client timeout/`messageerror` ⇒ terminate, orchestrator order; no test > 1 s.
- **Sizes** (measured; budget rows raised to them): background 334.6 KiB raw (+4.7), Firefox background 331.5 (+4.7), isolated CS 177.3 / 60.8 gzip (+5.6 / +1.9 — the ≤6 KiB estimate held), whole build 1839.2. Worker not emitted until P13C imports `build-client` (standalone 5.8 KiB raw / 2.2 gzip) — P13C adds its row.
