# P20: `nowprocket` context-menu entry

## TLDR

One page-scoped context-menu entry, **Open ?nowprocket**, opens the clicked document in a new tab with WP Rocket's cache-bypass parameter added when absent. Reuses the existing bypass vocabulary (`CACHE_BYPASS_QUERY_PARAM`, `isCacheBypassUrl` in `lib/wp-rocket/constants.ts`) and adds the one missing transform; one menu registry row plus its click arm. No permissions, storage, messaging, panel or SBS behavior change. Depends on the shipped P2 menu registry/router; independent of the active train (parallel P6G.12–.13/P10/P19). P19's menu refactor must carry the row unchanged as a menu-only command.

## P20A — menu row and URL transform

Depends: P2 (shipped). Parallel: P6G.12–.13, P10, P19. Size:S.

- [ ] URL owner (`lib/wp-rocket/constants.ts`, beside `CACHE_BYPASS_QUERY_PARAM`/`isCacheBypassUrl`): add `withCacheBypass(url: URL): string` — returns `url.href` unchanged when `isCacheBypassUrl(url)`; otherwise appends the **bare** `nowprocket` parameter (the owner's requested `?nowprocket`) while preserving the existing query and fragment: no query → `?nowprocket`, existing query → `&nowprocket`, fragment kept after the query. Preserve the existing search string exactly (append by string; never re-serialize through `URLSearchParams`, which re-encodes the user's query). Do not add a second parameter constant; re-point the SBS-local `NOW_PROCKET_PARAM` to `CACHE_BYPASS_QUERY_PARAM` (SBS's `=1` append/delete behavior stays byte-identical).
- [ ] Menu registry (`lib/wp-rocket/constants.ts` + `entrypoints/background/context-menus.ts`): id `openNowProcket`, title **Open ?nowprocket**, action `'open-nowprocket'`, `contexts: ['all']`, `documentUrlPatterns: URL_PATTERNS` — page-scoped http(s) documents like the SBS/chip rows; the click's `info.pageUrl` is the document, never the clicked link/image target. One row in `MENU_ENTRIES`; no submenu/separator changes. Correct the module header's stale entry count while there (it says "four" for today's five rows).
- [ ] Click arm: pure `menuBypassUrl(pageUrl: string | undefined): string | null` (parse + http(s) gate + `withCacheBypass`; missing/malformed/non-http(s) → null) so the decision is unit-testable. Dispatch opens the result through a new `openUrl(url, windowId)` dep → `browser.tabs.create({ url, ...(windowId === undefined ? {} : { windowId }) })` in the **click's own window** (the standing "the click event's tab, never a re-query of the active tab" rule), active by default. An already-bypassed URL opens unchanged (the click still does something honest). Unusable click → logged warn naming the action/tab only; a rejected `tabs.create` → logged error; never log the page URL (it can carry secrets) and never throw out of the listener.
