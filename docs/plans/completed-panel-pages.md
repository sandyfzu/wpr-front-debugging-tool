### Exclusion algorithm: retain the final safe form

Plugin saves through sanitize_text_field→rocket_clean_wildcards, then escapes `+/?ver/#` and tests **whole script tag**, not just URL. Broad `.*`, variable `[^/]{1,3}` stretches and pre-backslash escaping were rejected (silent sibling over-match and exponential backtracking). Final source in page model/pattern module is authoritative:

- Same-origin path, otherwise host+path; root single file keeps host, fileless first query ends `[&"']` so1≠10. Unknown inspected origin keeps host; origin eval validated exactHTTP and lastError-aware.
- Decode percent runs. Non-ASCII raw UTF-8; decoded ASCII exact alternatives raw literal-class or `[%]XX` (different initial bytes, deterministic). Unsafe raw class chars use `[^/%]`; slash encoded-only, percent `[%](?:25){0,1}`, undecodable bytes encoded. Apostrophe/ampersand support raw/numeric/named HTML entities. Optional forms use **{0,1}, not ?**, avoiding plugin `?ver` rewrite. Raw regex symbols represented as literal classes/dot where required by save pipeline. Display decoding keeps `%2F` encoded (no fake separators).
- Sibling corpus+save/escape readers pin own-script-only matches.30 encoded spaces/seeded60-name fuzz under50ms against4KiB lookalikes; exact encoded-ASCII alternative no longer matches a-b merely for a backtick. **Known limitation:** non-ASCII percent-encoded tag may fail visibly; safer than broad silent exclusion. Patterns never contain broad wildcard or bare `%XX` stripped by sanitizer.
