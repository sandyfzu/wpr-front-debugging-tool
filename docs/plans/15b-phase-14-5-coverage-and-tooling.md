## P14.5D0 — Served script URL on delayed scripts (pre-release fix, outside the gate)

**Done 2026-10-28** (owner: standalone, before release; on the P21 branch, reached `develop` with P21). Delay JS moves `src` to `data-rocket-src` (`DelayJS/HTML.php:254-256`), so on no-meta Delay pages `detectMinifyJs` missed minified scripts (real blind spot); the lazyload and beacon URL reads were latent. `lib/detection/served-script-src.ts`: `servedScriptSrc` (resolved, `<base>` honored) / `servedScriptSrcAttribute` (raw, for each check's own empty-`src` gate); `data-rocket-src` read only on a delayed `type` (suffix `rocketlazyloadscript`, any case). Side effect: both lazyload scans now test the resolved URL, not the raw attribute (same for real URLs; degenerate `..`/backslash paths can differ). Fixture `delay-on-no-meta.html` (real 3.24 Delay pass via the parity harness) ⇒ `minify_js` present by footprint in both engines. P21I and D4 reuse the helper.
