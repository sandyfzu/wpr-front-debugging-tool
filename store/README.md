# Store listing assets

Per-store checklist for the 3.0.0 submission. Never shipped: the store zips pack only the build output, and the Firefox sources zip excludes `store/**` (`wxt.config.ts` `zip.excludeSources`). Copy and dashboard fields: [listing.md](listing.md). Images: `pnpm store:assets` renders `assets/*.png` from `branding/icon.svg` (`scripts/generate-store-assets.mjs`; `--check` fails naming a drifted file); screenshots come from the shared capture script (P15E.3 wave 3, not yet).

Specs fetched 2026-11-23 from the official pages linked per section — re-fetch before submitting.

Status: ✅ produced · 🟡 draft, owner approval · ⬜ open.

## Chrome Web Store

Sources: [Images](https://developer.chrome.com/docs/webstore/images), [Store listing tab](https://developer.chrome.com/docs/webstore/cws-dashboard-listing), [Privacy tab](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy), [Best practices](https://developer.chrome.com/docs/webstore/best-listing). "Only the store icon and at least one screenshot are required."

| Asset / field                                                                     | Spec                                                                                                                                                                                                                                                        | Req.     | File / source                                       | Status |
| --------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- | --------------------------------------------------- | ------ |
| Store icon                                                                        | 128×128 PNG, 96×96 art + 16 px transparent per side; also in the zip                                                                                                                                                                                        | required | `assets/icon-128-padded.png` (= zip `icon/128.png`) | ✅     |
| Screenshots                                                                       | 1280×800 or 640×400, square corners, full bleed; ≥ 1, max 5 (5 recommended)                                                                                                                                                                                 | required | —                                                   | ⬜     |
| Small promo tile                                                                  | 440×280 PNG/JPEG; "Avoid text", fill the region, saturated colors                                                                                                                                                                                           | optional | `assets/promo-small-440x280.png`                    | 🟡     |
| Marquee promo tile                                                                | 1400×560 PNG/JPEG; same guidance; needed only to be featured in the marquee                                                                                                                                                                                 | optional | `assets/promo-marquee-1400x560.png`                 | 🟡     |
| YouTube video                                                                     | link                                                                                                                                                                                                                                                        | optional | —                                                   | skip   |
| Summary                                                                           | manifest `description`, ≤ 132 chars, plain text                                                                                                                                                                                                             | required | `package.json` → [listing.md](listing.md#summary)   | 🟡     |
| Description                                                                       | no stated limit; open with what it does                                                                                                                                                                                                                     | required | [listing.md](listing.md#description)                | 🟡     |
| Category                                                                          | one of the dashboard list                                                                                                                                                                                                                                   | required | Developer Tools                                     | 🟡     |
| Single purpose, permission justifications, remote code, data use + certifications | Privacy tab                                                                                                                                                                                                                                                 | required | [listing.md](listing.md#single-purpose-cws-edge)    | 🟡     |
| Privacy policy URL                                                                | required when user data is handled ([User Data FAQ](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq)); must state Limited Use compliance ([Limited Use](https://developer.chrome.com/docs/webstore/program-policies/limited-use)) | required | draft text in listing.md; URL owner                 | ⬜     |
| Official / homepage / support URL                                                 | optional                                                                                                                                                                                                                                                    | optional | owner                                               | ⬜     |

Promo tiles: the mark on its own tile color, no text (CWS: "Avoid text", "should primarily communicate the brand"); opaque edge to edge.

## Firefox AMO

Sources: [Creating an appealing listing](https://extensionworkshop.com/documentation/develop/create-an-appealing-listing/), [Add-on policies](https://extensionworkshop.com/documentation/publish/add-on-policies/), AMO server upload rules ([`constants/base.py`](https://github.com/mozilla/addons-server/blob/master/src/olympia/constants/base.py): `VALID_IMAGE_TYPES` PNG/JPEG, `ADDON_ICON_SIZES` 32/64/128; [`addons/serializers.py`](https://github.com/mozilla/addons-server/blob/master/src/olympia/addons/serializers.py): icon `required=False`, `require_square=True`), categories [API](https://addons.mozilla.org/api/v5/addons/categories/).

| Asset / field         | Spec                                                                                    | Req.                        | File / source                                                                                               | Status |
| --------------------- | --------------------------------------------------------------------------------------- | --------------------------- | ----------------------------------------------------------------------------------------------------------- | ------ |

| Screenshots           | 1280×800 recommended (max display), else 1.6:1; no practical count limit                | optional (strongly advised) | —                                                                                                           | ⬜     |
| Summary               | ≤ 250 chars                                                                             | required                    | [listing.md](listing.md#summary)                                                                            | 🟡     |

| Categories            | up to 2                                                                                 | required                    | Web Development                                                                                             | 🟡     |
| Support email         | "consider offering an email address" (advice; `support_email` not required)             | optional (recommended)      | owner                                                                                                       | ⬜     |
| Privacy policy        | required when personal data (incl. browsing activity) is used; full text in the listing | required                    | draft text in listing.md                                                                                    | 🟡     |
