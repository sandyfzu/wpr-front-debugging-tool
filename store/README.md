# Store listing assets

Per-store checklist for the 3.0.0 submission. Never shipped: the store zips pack only the build output, and the Firefox sources zip excludes `store/**` (`wxt.config.ts` `zip.excludeSources`). Copy and dashboard fields: [listing.md](listing.md). Support team note before rollout: [support-heads-up.md](support-heads-up.md). User-facing changes: [CHANGELOG.md](../CHANGELOG.md). Store-policy audit receipts: [P15D](../docs/plans/16-phase-15-hardening-release.md#p15d--docsrelease). Images: `pnpm store:assets` renders `assets/*.png` from `branding/icon.svg` (`scripts/generate-store-assets.mjs`; `--check` fails naming a drifted file); screenshots: `pnpm screenshots:release` (`scripts/release-shots.ts`; needs `pnpm build` + the docker site) writes `screenshots/*.png`.

Specs fetched 2026-11-23 from the official pages linked per section — re-fetch before submitting.

Status: ✅ produced · 🟡 draft, owner approval · ⬜ open.

## Screenshots

`screenshots/`, 1280×800 PNG (fits all three stores), light theme, real shipped UI on the local docker site (no customer data; the address shown is the local `127.0.0.1` site), laid out at 640×400 and shot at 2× so the text stays readable at CWS's 640×400 display size, numbered best first: 01 Detections panel · 02 Exclusion Builder (a Delay JS row applied) · 03 detection widget · 04 RUCSS Tester (after a test) · 05 Beacon Tester (after a run) · 06 command palette · 07 options. Staged data: the RUCSS service answer (unreachable from a local site) is the page's own matching CSS rules; the time shown (clock, WP Rocket's cache stamp) is pinned so re-runs are byte-identical. CWS takes 01–05, Edge 01–06, AMO all.
