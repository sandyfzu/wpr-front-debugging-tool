A script from the second origin throws uncaught

Loads cross-origin-throw.js from 127.0.0.1 while this page itself is served from localhost — distinct origins for the browser, so the uncaught error's message is withheld and reported as Script error. (the sentinel path of the undefined-references capture).

The injection is deferred so the page has fully loaded first: the browser-test suite then starts observing from a settled baseline and measures the throw → receiver round-trip with page-local clocks.
